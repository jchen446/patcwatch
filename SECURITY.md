# Security

Patcwatch v0.1 is a local beta application. Do not host it on the public Internet or use it as a multi-user server.

Please report suspected vulnerabilities privately through the repository's GitHub Security advisory reporting if enabled. Otherwise, open an issue asking for a private contact without posting exploit details, credentials or private feedback.

The Python audit guard supports the zero-outbound experiment; it is not a hardened OS sandbox. No untrusted plugins or native extensions are supported. Only use source files and exporters you trust. The UI renders feedback as text, never executable markup.
